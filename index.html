Project Reflection

  1. For this independent project, I chose to explore how to make simple games using JavaScript. This interested me because I like programming, but I had never before made a game with programming because I mostly use programming to make algorithms that solve problems.
  2. I chose to make the classic dinosaur game because it is simple and straight forward.
  3. A few interesting, useful, and new things that I learned during this project is how to make a wait time in JavaScript, how to call a function through a button press, and how to make more animations using CSS.
  4. One moment of joy I had while making this project was at the end, when I had no idea if my game would work or not and it actually did work.
